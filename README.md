# 比特工坊 · BitCraft

**从一个逻辑门开始，造出属于你的计算机。**

一款融合数字电路搭建与解谜的网页休闲游戏。连接开关和逻辑门，点亮第一盏灯；把小电路封装成零件，拼出能计算、能记忆的机器；最后给自己的计算机写下程序，完成一个个工坊挑战。

> 当前状态：项目初始化与设计阶段。仓库仅包含项目说明和规划，尚未实现游戏功能，也没有可运行的演示版本。下文的玩法均为计划内容。

## 游戏定位

“数字电路沙盒 + 计算机组装 + 编程闯关”，以轻松、直观的搭建体验，让玩家逐步理解计算机如何工作。

- **面向玩家**：喜欢搭建、解谜和自动化的玩家，以及对计算机原理好奇的初学者。
- **目标平台**：网页，第一阶段优先支持桌面浏览器的鼠标与键盘操作。
- **游戏节奏**：短关卡、即时反馈、自由试错；不要求先学完一套理论。
- **模拟范围**：从理想化的数字逻辑电路开始，用 `0` 和 `1` 表示信号。首版不模拟电压、电流、电阻、电容等模拟电路行为。

## 三层玩法

| 层次 | 玩家做什么 | 能看见的成果 |
| --- | --- | --- |
| 数字电路沙盒 | 放置元件、连接引脚、切换输入、观察信号 | 开关控制灯、逻辑判断、加法电路 |
| 计算机组装 | 把验证过的电路封装为模块，搭建运算与存储部件 | 寄存器、算术逻辑单元、内存和简化 CPU |
| 编程闯关 | 为自己搭建的简化计算机编写小程序并单步运行 | 完成计算、条件判断、循环和自动控制挑战 |

三个层次按学习进度逐步展开。首个版本聚焦数字逻辑沙盒与入门关卡，计算机组装和编程闯关留到后续阶段。

远期目标是让玩家在亲手搭建的 8 位计算机上显示 `HELLO`，再挑战运行简单的小游戏。

## 核心循环

```text
接到小挑战 → 放置零件 → 连接电路 → 运行并观察 → 调整与验证
                                                    ↓
                            完成挑战 → 解锁元件 → 尝试下一关或自由搭建
```

例如：“只有两个开关都打开，工坊的门灯才亮。”玩家连接两个输入、一个 AND 门和一盏灯，试出四种输入组合，再提交验证。

## 首个可玩版本的范围

- 网格画布：放置、移动、删除元件，连接与断开导线，缩放和平移。
- 基础元件：输入开关、输出灯、NOT、AND、OR、XOR。
- 信号反馈：显示 `0/1` 状态与导线发光动画，清楚指出未连接的输入和不合法接线。
- 电路求值：只支持无组合环路的单比特组合逻辑，输入变化后更新输出。
- 两种入口：自由沙盒与六个入门关卡，关卡按完整真值表验证。
- 基础存档：在本地保存作品和关卡进度，支持作品文件导入与导出。

详细交互、关卡示例和模拟规则见 [玩法设计](docs/GAME_DESIGN.md)；阶段范围与验收条件见 [开发路线](docs/ROADMAP.md)。

## 开发状态

本次初始化不包含应用脚手架、依赖安装、服务部署或 Plane Lite 代码迁移。开始实现时，先完成“开关 → 导线 → 灯”的最小交互原型，再扩展为逻辑门和关卡系统。

候选技术方向为 Vue 3 + TypeScript 构建界面、PixiJS 承载画布，尚未安装依赖或确定版本。最终技术选型、美术风格、发布方式与许可证在后续阶段确定；当前不承诺开发排期。
