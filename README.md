# 比特工坊 · BitCraft

**从一个逻辑门开始，造出属于你的计算机。**

一款融合数字电路搭建与解谜的网页休闲游戏。连接开关和逻辑门，点亮第一盏灯；把小电路封装成零件，拼出能计算、能记忆的机器；最后给自己的计算机写下程序，完成一个个工坊挑战。

> 当前状态：首个可玩版本 v0.1。数字逻辑沙盒、六个入门关卡与本地作品库已经实现；芯片封装、时序电路、CPU 和编程仍在后续规划中。

## 本地启动

需要 Node.js 20.19+ 或 22.12+，推荐使用 Node.js 22。

```bash
npm ci
npm run dev
```

打开 [本地工坊](http://localhost:5177)。开发服务器默认只监听本机，端口固定为 `5177`；若端口被占用会报错，请先关闭冲突的服务。

```bash
npm test          # 逻辑引擎、关卡、存档测试
npm run check    # TypeScript 检查
npm run build    # 类型检查与生产构建，输出到 dist/
npm run preview  # 预览生产构建：http://localhost:4177
```

游戏为纯前端，无需数据库、账号或 API 密钥。页面字体、图形和逻辑不依赖外部 CDN；正式部署时将 `dist/` 交给静态 Web 服务器，不要直接双击 `index.html`。

## 怎么玩

1. 默认沙盒带有一个可操作的与门示例，按下两个开关观察指示灯。
2. 从左侧拖入元件，或点击元件把它放到画布中央。
3. 点击元件右侧输出圆点，再点击另一个元件左侧输入圆点，也可直接拖拽接线。
4. 进入“挑战关卡”，按手册目标搭建并点击“验证电路”。验证器检查所有输入组合。
5. “保存作品”将电路加入本地作品库；底部“导出”和“导入”用于文件备份及跨设备使用。

空格拖动可平移画布，滚轮缩放，`0` 适应全部元件；`Delete` 删除选中项，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做。选中元件后可用方向键移动。

每个作品最多 128 个元件、256 条导线，导入文件最大 1 MB，作品库最多 12 个作品。保存按浏览器和网站地址隔离：`localhost` 与 `127.0.0.1` 的存档相互独立。清除浏览器数据会移除本地作品，请导出需要长期保留的文件。

## 游戏定位

“数字电路沙盒 + 计算机组装 + 编程闯关”，以轻松、直观的搭建体验，让玩家逐步理解计算机如何工作。

- **面向玩家**：喜欢搭建、解谜和自动化的玩家，以及对计算机原理好奇的初学者。
- **目标平台**：网页，第一阶段优先支持桌面浏览器的鼠标与键盘操作。
- **游戏节奏**：短关卡、即时反馈、自由试错；不要求先学完一套理论。
- **模拟范围**：从理想化的数字逻辑电路开始，用 `0` 和 `1` 表示信号。首版不模拟电压、电流、电阻、电容等模拟电路行为。

## 三层玩法

| 层次 | 玩家做什么 | 能看见的成果 |
| --- | --- | --- |
| 数字电路沙盒 | 放置元件、连接引脚、切换输入、观察信号 | 开关控制灯、逻辑判断、加法电路 |
| 计算机组装 | 把验证过的电路封装为模块，搭建运算与存储部件 | 寄存器、算术逻辑单元、内存和简化 CPU |
| 编程闯关 | 为自己搭建的简化计算机编写小程序并单步运行 | 完成计算、条件判断、循环和自动控制挑战 |

三个层次按学习进度逐步展开。当前版本聚焦数字逻辑沙盒与入门关卡，计算机组装和编程闯关留到后续阶段。

远期目标是让玩家在亲手搭建的 8 位计算机上显示 `HELLO`，再挑战运行简单的小游戏。

## 核心循环

```text
接到小挑战 → 放置零件 → 连接电路 → 运行并观察 → 调整与验证
                                                    ↓
                            完成挑战 → 解锁元件 → 尝试下一关或自由搭建
```

例如：“只有两个开关都打开，工坊的门灯才亮。”玩家连接两个输入、一个 AND 门和一盏灯，试出四种输入组合，再提交验证。

## 当前已实现

- 网格画布：放置、移动、删除元件，连接与断开导线，缩放和平移。
- 基础元件：输入开关、输出灯、NOT、AND、OR、XOR。
- 信号反馈：显示 `0/1` 状态与导线发光动画，清楚指出未连接的输入和不合法接线。
- 电路求值：只支持无组合环路的单比特组合逻辑，输入变化后更新输出。
- 两种入口：自由沙盒与六个入门关卡，关卡按完整真值表验证。
- 基础存档：在本地保存作品和关卡进度，支持作品文件导入与导出。
- 编辑工具：元件命名、撤销与重做、固定关卡端口保护、引脚键盘接线。
- 作品库与手册：保存命名作品、重新打开、渐进提示、可关闭的信号动画。

详细交互、关卡示例和模拟规则见 [玩法设计](docs/GAME_DESIGN.md)；阶段范围与验收条件见 [开发路线](docs/ROADMAP.md)。

## 开发状态

当前采用 Vue 3 + TypeScript + Vite。第一版使用 SVG 画布，便于实现可访问的引脚交互、检查电路状态和控制依赖规模；模拟引擎不依赖渲染方式，未来可按性能需求评估 PixiJS。

优先支持桌面浏览器。窄窗口使用可展开的手册面板，完整手机触屏操作尚未验收。线上部署、许可证、芯片封装与后续计算机系统尚未完成。
