# 比特工坊：开发路线

[项目介绍](../README.md) · [玩法设计](GAME_DESIGN.md)

状态：阶段 0–2 已完成，阶段 3 的组合芯片封装、个人芯片库和全加器已实现；时序部分与阶段 4–5 未开始。线上部署不在当前交付范围。以下同时列出已完成范围与后续验收目标，不承诺后续交付日期。

## 阶段 0：项目初始化

- [x] 明确“数字电路沙盒 + 计算机组装 + 编程闯关”的定位。
- [x] 确定先做理想数字逻辑，不从模拟电路起步。
- [x] 记录核心循环、首版元件和六个入门关卡。
- [x] 建立项目介绍、设计草案与开发路线。
- [x] 添加基础文本格式与 Git 忽略规则。

验收：仓库内容能清楚说明游戏要做什么、首版做多少，以及下一步从哪里开始；不包含尚未验证的应用脚手架。

## 阶段 1：最小交互原型

目标：验证“亲手接线，立即看到结果”的体验。

- [x] 确定前端技术方案与本地启动方式。
- [x] 实现元件、引脚、导线与电路图数据结构。
- [x] 支持放置、移动输入开关和输出灯。
- [x] 支持合法接线、断线、选择与删除。
- [x] 实现单比特信号求值和画面反馈。
- [x] 加入画布缩放、平移与基础撤销。

验收：玩家能从空画布搭出“开关 → 导线 → 灯”，切换开关时灯正确更新；移动元件后连接仍有效；断开导线后清楚显示未定义状态。

## 阶段 2：数字逻辑首个可玩版本

目标：完成可以自由搭建、也可以连续闯关的第一版游戏。

- [x] 加入 NOT、AND、OR、XOR 与元件说明。
- [x] 展示信号发光与流动动画，并提供减弱或关闭动画的选项。
- [x] 检测重复驱动、不合法连接与组合环路。
- [x] 实现六个入门关卡、提示和完整真值表判定。
- [x] 加入过关反馈与关卡进度。
- [x] 支持自由沙盒、本地保存及作品导入导出。
- [x] 明确并验证画布元件数量与存档大小上限。
- [x] 提供可访问的试玩构建与启动说明。

验收：六关均可完成；不同结构的正确电路同样能通过；错误电路给出可解释的失败原因；刷新后作品可恢复，导出再导入保留电路和布局。

应在此阶段实施的验证：

- 逻辑门的全部输入组合与复合电路输出。
- 接线冲突、未定义信号和环路的诊断。
- 关卡通过、失败反例与保存恢复。
- 非法存档不会覆盖当前作品或执行代码。
- 浏览器内从接线到通关的实际操作流程。

## 阶段 3：模块化与时序电路

目标：让玩家把已学到的电路当作新零件使用，并理解“记忆”。

- [x] 支持整个工作台封装为组合芯片，定义命名输入输出（每侧最多 4 个）。
- [x] 建立个人芯片库，支持多输出接线、芯片复制、功能表查看与文件携带。
- [x] 加入全加器、信号选择器关卡，半加器可复用于全加器组装。
- [ ] 支持选中局部电路封装、芯片内部展开编辑。
- [ ] 加入多位加法器关卡。
- [ ] 引入离散时钟、暂停与单步。
- [ ] 加入寄存器、计数器与状态观察。
- [ ] 设计时序关卡，按输入序列和时钟步验证结果。

验收：封装前后的电路行为一致；时序电路在相同初始状态和输入序列下结果一致；玩家能单步观察寄存器如何保存与更新数据。

## 阶段 4：计算机组装

目标：从模块搭出一台可观察、可运行的简化计算机。

- [ ] 明确字长、总线规则、存储规模与最小指令集。
- [ ] 提供多位总线、ALU、内存及控制模块。
- [ ] 设计由浅入深的部件组装关卡。
- [ ] 展示取指、解码、执行与状态变化。
- [ ] 提供一台经过验证的参考计算机。

验收：参考计算机可以加载并执行约定的示例程序；玩家组装的计算机能通过相同的行为测试，且运行过程可单步检查。

## 阶段 5：编程闯关

目标：让玩家通过程序控制前面搭建的计算机。

- [ ] 实现适合初学者的类汇编编辑与错误提示。
- [ ] 通过参考计算机引导读写、运算、条件与循环。
- [ ] 提供暂停、单步、重置与状态检查。
- [ ] 加入输入输出验证、执行步数上限和停止操作。
- [ ] 允许选择经过基础校验的玩家计算机运行挑战。
- [ ] 接入简化显示与键盘模块，完成 `HELLO` 输出挑战。

验收：玩家能完成计算和控制类挑战；错误程序提供可定位的反馈，无限循环能够停止；同一程序在符合约定的参考计算机与玩家计算机上得到一致结果。

## 后续候选方向

以下内容暂不排期，是否开展取决于试玩反馈：

- 工坊外观、装饰和更丰富的委托主题。
- 在玩家搭建的计算机上运行弹球、贪吃蛇等简单游戏。
- 更多电路与编程关卡、可选的元件数量优化挑战。
- 作品分享、关卡编辑器、账号与云存档。
- 平板与触屏适配。

真实模拟电路、复杂物理仿真和多人实时协作不作为当前路线的前置条件。
