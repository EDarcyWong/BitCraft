# 开发与验证

## 当前架构

| 模块 | 职责 |
| --- | --- |
| `src/core/circuit.ts` | 元件与导线数据模型、组合逻辑求值、连接合法性、导入电路校验 |
| `src/core/levels.ts` | 八个关卡、固定端口、元件范围、真值表判定与提示 |
| `src/core/storage.ts` | v1 / v2 作品读取、v2 存档、旧存档迁移、芯片库与数据约束 |
| `src/composables/useWorkshop.ts` | 电路编辑、50 步撤销历史、关卡草稿、自动保存、作品库 |
| `src/components/CircuitCanvas.vue` | SVG 元件、导线、坐标变换、接线、拖动、缩放与键盘交互 |
| `src/App.vue` | 工坊、挑战手册、元件库、作品库、导入导出和通关反馈 |

引擎按依赖顺序求值，输入缺失时传播 `null`（未定义），相同输入得到相同结果。导线动画只表示信号状态，不参与逻辑计算。当前不模拟时钟、反馈、真实传播延迟或模拟电路。

芯片通过 `compileChip` 对整个电路穷举输入，编译为最多 16 行、每行最多 4 位的真值表。输入开关与输出灯按 `(y, x, id)` 排序成为命名端口；缺失、重复命名、未定义输出会拒绝封装。芯片包含功能快照，不递归嵌入子电路，重复封装不会造成递归求值或展开规模爆炸。

`Wire.fromPin` 指定来源输出端口，旧连线省略时默认为 0；信号 Map 的第一个输出仍用节点 ID，额外输出使用 `id:pin`，导入 ID 禁止冒号以避免冲突。每次放置、复制、撤销、导出都会保留独立的芯片功能副本。

SVG 适合当前 128 个元件的有限工作台，也让引脚具有可访问名称和键盘操作。求值代码没有导入 Vue 或 DOM，后续可独立扩展渲染器或模拟规则。

## 存档与错误处理

- 进度、沙盒草稿、每关草稿、作品库和最多 24 块芯片保存在 `bitcraft:studio:v1`；保留原存储键以找到旧存档，内容版本升级为 2。
- 编辑后延迟 350 毫秒保存；页面隐藏或退出时提交最后的状态。
- 新作品文件标记为 `format: "bitcraft-circuit"`、`version: 2`，包含名称、电路及芯片功能快照；兼容读取 v1 文件。v1 本地存档自动补齐空芯片库，已有草稿、收藏、进度不变。
- 导入先校验所有元件和连线，成功后再替换工作台；不支持的版本、未知元件、重复编号、无效坐标、重复驱动和环路均被拒绝。
- 本地存档损坏时显示提示，暂停自动覆盖；主动保存作品时先保留原数据到恢复备份键。
- 存储空间不足或浏览器禁止存储时，界面显示保存失败，仍可继续搭建并导出 JSON 文件。
- 撤销历史属于本次编辑会话，不写入长期存档。切换关卡或重新打开作品会清空撤销历史。

```bash
npm ci
npm test
npm run build
```

Vitest 目前覆盖 59 项测试：逻辑门全部输入、断线与未定义传播、扇出、乱序依赖、128 元件长链、非法接线、组合环路、完整八关、芯片编译和复用、多输出端口、独立快照、四输入四输出上限、固定端口约束、导入导出和 v1 存档迁移。

生产构建先执行严格 TypeScript 检查。GitHub Actions 在 Linux 和 Windows 上使用 Node.js 22 执行依赖安装、测试及构建，并在 Linux Chromium 中运行端到端测试，失败时上传截图和 trace。

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Windows 可使用已安装的 Edge：PowerShell 中先运行 `$env:E2E_CHANNEL = 'msedge'`。端到端测试使用独立临时浏览器上下文及生产预览端口 4177，不修改用户浏览器存档。
